# Website brand assets

See [master brand README](../../branding/README.md). These are Figma-exported logo and favicon candidates for the website; currently no website UI code is integrated.

Use `favicon.svg` or `favicon-32.png` for browser tabs, `apple-touch-icon-180.png` for touch bookmarks, `favicon-192.png` / `site-mark-512.png` for PWA, `logo-horizontal-light.svg` / `logo-horizontal-dark.svg` for page headers, and `social-preview-1200x630.jpg` for Open Graph.
